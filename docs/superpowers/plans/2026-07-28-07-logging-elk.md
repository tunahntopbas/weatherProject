# Loglama (ElasticSearch + Kibana) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `06-kubernetes-rancher.md`'de deploy edilen `backend`/`frontend` pod'larının loglarını merkezi olarak toplamak, saklamak (ElasticSearch) ve aranabilir/görselleştirilebilir hale getirmek (Kibana).

**Architecture:** Her 3 node'da bir `Filebeat` (DaemonSet — her node'da otomatik olarak bir kopya çalışır) container loglarını okur, ElasticSearch'e gönderir. Kibana, ElasticSearch üzerindeki bu logları arama/görselleştirme arayüzü sunar. Neden bu üçlü: tek başına ElasticSearch sadece veri saklar (arayüzü yok), tek başına Kibana'nın gösterecek verisi olmaz, Filebeat olmadan loglar container'ların içinde kilitli kalır ve pod silindiğinde kaybolur.

**Tech Stack:** ElasticSearch 8.x, Kibana 8.x, Filebeat 8.x (Elastic'in resmi Kubernetes log toplayıcısı), Kubernetes DaemonSet/StatefulSet/RBAC.

## Global Constraints

- Namespace: `logging` (uygulama namespace'i olan `weatherproject`'ten ayrı — loglama altyapısı uygulamadan bağımsız bir kaygı)
- ElasticSearch/Kibana sürümleri birbiriyle aynı major.minor olmalı (`8.x` - `8.x`), aksi halde uyumsuzluk hatası alınır
- Bu, tek-node (single-node) ElasticSearch kurulumudur — öğrenme/geliştirme amaçlıdır, production'da en az 3 node'lu bir ES cluster'ı (yüksek erişilebilirlik için) kurulur
- `xpack.security.enabled=false` kullanılacak (öğrenme ortamında kimlik doğrulama karmaşıklığını azaltmak için) — production'da bu asla kapatılmaz, `08-monitoring-grafana.md`'de veya ileride bir "sertleştirme" notu olarak hatırlanmalı

### Task 4: Filebeat DaemonSet — pod loglarını toplama

**Files:**
- Create: `k8s/logging/filebeat-rbac.yaml`
- Create: `k8s/logging/filebeat-configmap.yaml`
- Create: `k8s/logging/filebeat-daemonset.yaml`

**Interfaces:**
- Consumes: `elasticsearch` Service (Task 2), tüm node'lardaki `/var/log/containers` (container runtime'ın log dosyaları)
- Produces: ElasticSearch'te `filebeat-*` index deseni altında `weatherproject` namespace'indeki tüm pod loglarının kopyası. Task 5'te Kibana'da bu index görüntülenecek.

**Neden DaemonSet (Deployment değil):** Filebeat her node'un kendi diskindeki log dosyalarını okumalı. `Deployment` pod'ları rastgele bir node'a yerleştirir (tek node'un loglarını okur, diğer ikisini kaçırır). `DaemonSet`, Kubernetes'e "bu pod'dan **her node'da tam olarak bir tane** çalıştır" der — bu yüzden node sayısı arttıkça Filebeat de otomatik büyür.

- [ ] **Step 1: RBAC (Filebeat'in Kubernetes API'sinden pod/namespace bilgisi okuma izni)**

```yaml
# k8s/logging/filebeat-rbac.yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: filebeat
  namespace: logging
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: filebeat
rules:
  - apiGroups: [""]
    resources: ["namespaces", "pods", "nodes"]
    verbs: ["get", "watch", "list"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: filebeat
subjects:
  - kind: ServiceAccount
    name: filebeat
    namespace: logging
roleRef:
  kind: ClusterRole
  name: filebeat
  apiGroup: rbac.authorization.k8s.io
```

**Neden bu RBAC gerekli:** Filebeat, sadece "ham log satırlarını" değil, hangi pod'dan/namespace'ten/container'dan geldiğini de etiketlemek ister (Kubernetes autodiscover özelliği). Bunu yapabilmesi için Kubernetes API'sinden pod/namespace metadata'sını okuma iznine ihtiyacı vardır — bu izin `ClusterRole` + `ClusterRoleBinding` ile verilir.

- [ ] **Step 2: Filebeat yapılandırmasını (ConfigMap) yaz**

```yaml
# k8s/logging/filebeat-configmap.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: filebeat-config
  namespace: logging
data:
  filebeat.yml: |
    filebeat.autodiscover:
      providers:
        - type: kubernetes
          node: ${NODE_NAME}
          hints.enabled: true
          templates:
            - condition:
                contains:
                  kubernetes.namespace: weatherproject
              config:
                - type: container
                  paths:
                    - /var/log/containers/*${data.kubernetes.container.id}.log

    output.elasticsearch:
      hosts: ["http://elasticsearch.logging.svc.cluster.local:9200"]

    setup.kibana:
      host: "kibana.logging.svc.cluster.local:5601"
```

**Neden `kubernetes.namespace: weatherproject` filtresi:** Filtre olmadan Filebeat cluster'daki **tüm** namespace'lerin loglarını (Kubernetes sistem bileşenleri dahil) toplar — bu, öğrenme aşamasında gürültüyü artırır ve ES diskini gereksiz doldurur. Sadece uygulamamızın namespace'ine odaklanmak, Kibana'da aradığını bulmayı kolaylaştırır.

- [ ] **Step 3: DaemonSet'i yaz**

```yaml
# k8s/logging/filebeat-daemonset.yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: filebeat
  namespace: logging
spec:
  selector:
    matchLabels:
      app: filebeat
  template:
    metadata:
      labels:
        app: filebeat
    spec:
      serviceAccountName: filebeat
      containers:
        - name: filebeat
          image: docker.elastic.co/beats/filebeat:8.14.3
          args: ["-c", "/etc/filebeat.yml", "-e"]
          env:
            - name: NODE_NAME
              valueFrom:
                fieldRef:
                  fieldPath: spec.nodeName
          volumeMounts:
            - name: config
              mountPath: /etc/filebeat.yml
              subPath: filebeat.yml
              readOnly: true
            - name: varlogcontainers
              mountPath: /var/log/containers
              readOnly: true
            - name: varlogpods
              mountPath: /var/log/pods
              readOnly: true
            - name: varlibdockercontainers
              mountPath: /var/lib/docker/containers
              readOnly: true
      volumes:
        - name: config
          configMap:
            name: filebeat-config
        - name: varlogcontainers
          hostPath:
            path: /var/log/containers
        - name: varlogpods
          hostPath:
            path: /var/log/pods
        - name: varlibdockercontainers
          hostPath:
            path: /var/lib/docker/containers
```

- [ ] **Step 4: Uygula ve doğrula**

